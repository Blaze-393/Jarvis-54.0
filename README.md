# 🤖 Джарвис — текстовый помощник на Python

Текстовый ассистент в стиле Джарвиса из «Железного человека». Работает в терминале, не требует интернета (кроме команд, которые открывают сайты), хранит выученные фразы в JSON.

## Возможности

- 🧮 Калькуляторы: обычный, физический (7 формул), вычисления в системах счисления 2–16
- 🔐 Шифрование: Base64, перевод текста в любую систему счисления (UTF-8 и посимвольно)
- 📁 Файлы: список, чтение, создание, удаление в `~/Documents`
- 🎮 Игры: угадай число, пенальти, крестики-нолики
- 🧪 Протоколы: диагностика, бэкап, таймер, «ночной страж», «варп», «матрица» и другие (в основном шуточные)
- 🗣️ Диалоги: база фраз, которую можно пополнять и редактировать прямо из консоли
- 🌐 Сайты и приложения: открывает YouTube, GitHub, Википедию, погоду, курсы валют и т.д.
- ⏱️ Утилиты: секундомер, генератор паролей, кубик/монетка, напоминания
- 📚 Факты и шутки: случайные научные факты и шутки про программирование

## Требования

- Python 3.8+
- macOS
- Быстрые команды с названиями из кода для открытия приложений (или можно поменять названия из кода на Ваши)

Сторонние библиотеки не нужны — только стандартная библиотека Python.

## Запуск

```bash
git clone https://github.com/ваш-username/jarvis.git
cd jarvis
python jarvis.py
```

При первом запуске создастся файл памяти ~/Documents/jarvis_templates_v2.json.

## Структура

jarvis.py                  # весь код
~/Documents/
  ├── jarvis_templates_v2.json   # выученные фразы
  └── reminders.json             # напоминания

## Настройка

- База фраз хранится в ~/Documents/jarvis_templates_v2.json. Её можно редактировать вручную или командами редактировать <слово> <ответ> и удалить <слово>.
- Команды shortcuts://run-shortcut?name=... заточены под macOS. На других ОС замените их на webbrowser.open(...) с нужными URL.
